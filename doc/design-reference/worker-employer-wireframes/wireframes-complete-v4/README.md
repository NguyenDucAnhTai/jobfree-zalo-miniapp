# Expanded JobFree wireframe archive

Original archive: `source-wireframes.zip` (preserved unchanged). PNG exports have been extracted here for reference.

## What this archive adds

Compared with the earlier archive, this ZIP contains additional onboarding and identity verification screen exports, including OTP, identity verification, VNeID consent/connection states, face verification, verification success, and profile completion. It also includes the previously supplied worker home, jobs, schedule, wallet, account, skills, and offer dialog screens.

## Important audience note

Although the archive filename says “Worker & Employer,” the screens visible in the exports are still predominantly Worker flows. The home screen offers nearby jobs to a Worker; the identity screen says verification builds Employer trust; the navigation is Worker home/jobs/schedule/wallet/account; and the wallet shows Worker earnings. No clearly identifiable Employer home, service catalog, request creation, or employer job tracking screens are present here. Treat this as the expanded **Worker-side** visual reference until Employer screens are identified.

## Handling note

Use these exports as visual/product reference only. Screens depicting identity documents, VNeID, face scans, OTP, or financial information do not authorize implementing real identity verification, collecting sensitive data, connecting VNeID, or processing money. The current frontend scope remains demo-only unless separately approved and specified.

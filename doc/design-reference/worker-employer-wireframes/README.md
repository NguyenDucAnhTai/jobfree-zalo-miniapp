## Design-reference scope

Both archive titles mention Worker and Employer, but the supplied screen exports visibly show the **Worker** experience (for example, “Sẵn sàng nhận việc hôm nay?”, job offers, shifts, worker wallet, and worker profile). The expanded archive adds onboarding and verification states but still does not contain clearly identifiable Employer home/service/request screens. Preserve these assets as the Worker-side Figma reference; do not use them as the Employer visual standard. Add the Employer Figma exports here when supplied/identified.

The handoff notes that the original Figma/Sketch source may contain additional screens. These exported PNGs are the visual references available in this archive; no pixel dimensions or unprovided design tokens are inferred here.
